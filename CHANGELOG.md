# Changelog

## 1.0.0 - 2026-10-03

- The MCP server address is `https://api.0tx.app/mcp`, the address the server's OAuth resource metadata names.
- Manifests for four plugin formats: `.cursor-plugin`, `.grok-plugin`, `.claude-plugin` and `.codex-plugin`.
- `mcp.json` and `.mcp.json` with the same content.
- Three skills: `0tx` (finding ledgers and reading them), `0tx-post-entries` (posting and correcting entries) and `0tx-review-period` (reviewing a date range).
- Logo drawn from the 0tx mark as paths, with a 512x512 PNG.
- `scripts/check.sh` and `scripts/build-openai-zip.sh`.

## 0.1.0 - 2026-08-28

- First draft with one skill and one MCP entry.
